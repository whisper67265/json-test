[#conversion]
= 值转换 虽然 &lt;<ref_value>&gt; 容器便于创建临时结构，但通常需要在 JSON 与用户定义类型或标准库中的类型之间进行转换。</ref_value>

函数模板 &lt;<ref_value_from>&gt; 提供了从类型 `T` 构造 &lt;<ref_value>&gt; 的接口。函数模板 &lt;<ref_value_to>&gt; 则进行相反方向的转换，从类型 `T` 转换为 &lt;<ref_value>&gt;。两者都支持多种不同的 https://en.cppreference.com/w/cpp/language/types[基础类型]，如 `int` 或 `double`，以及标准库类型，如 `std::string` 或 `std::vector<t>`，并且可扩展以支持用户定义类型。</t></ref_value></ref_value_to></ref_value></ref_value_from>
